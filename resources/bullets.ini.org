; ========================================================
; Bullet types
; ========================================================
; Every section is a bullet, named by the section: [ROCKET_NORMAL]
; Bullet names must be in capitals and known to the game, others are skipped.
;
; BitmapWidth=width in pixels of the bullet
; BitmapFrames=frames the bullet animates (0 = no animation)
; BitmapExplFrames=frames of the explosion
; MoveSpeed=ticks needed to move 1 pixel (higher = slower)
; DamageVehicle/DamageInfantry=damage done on impact
; ExplosionSize=square explosion in tiles, 2 means 2x2, etc.
; DeviateProbability=chance in % to deviate a unit (change sides)
; GroundBullet=true gets blocked by walls, mountains, structures; false flies over (rockets)
; CanDamageAirUnits=true can damage air units on impact
; CanDamageGround=true can damage walls, slabs, etc.
;
; Bitmap=name of the image in the graphics data (no key = no image)
; Sound=name of the sound played when shot (no key = silent)
; DeviateSound=name of the sound played when a unit is deviated (no key = silent)
; DeathParticle=particle spawned when the bullet dies, without the D2TM_PARTICLE_ prefix (no key = none)
; SmokeParticle=particle spawned while the bullet travels, same naming (no key = none)
; A bullet without a section gets defaults and does nothing.
