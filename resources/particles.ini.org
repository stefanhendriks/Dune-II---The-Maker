; Particles: the effects drawn on the map (explosions, smoke, tracks, order indicators).
; Every section is a particle, named like the D2TM_PARTICLE_ constant without that prefix: [EXPLOSION_TRIKE].
; Other names are skipped. A particle without a section has no bitmap. Keys that are absent use the default.
;
; Bitmap=name of the bitmap in the game graphics (no key = nothing is drawn)
; StartAlpha=opacity at spawn, 0-255 (default -1 = fully opaque)
; AdditiveBlending=true or false (default)
; Layer=TOP (default, drawn over units) or BOTTOM (drawn beneath units)
; FrameWidth=, FrameHeight=size in pixels of one animation frame (default 32 x 32)
;
; When a particle is spawned:
; FrameTimer=ticks (of 5 ms) before the first frame change (default 10), FrameTimerRandom=n adds a random 0 .. n-1
; DeadTimer=ticks the particle lives before it starts to fade out (default 0), DeadTimerRandom=n adds a random 0 .. n-1
; StartAlphaRandom=n adds a random 0 .. n-1 to StartAlpha
; AnchorBottom=true when the position of the particle is the bottom of its bitmap instead of the center (default false)
; Spawn1=, Spawn2=, Spawn3=particle that is spawned together with this one, for example OBJECT_BOOM02. Each takes
;   Spawn1OffsetX=, Spawn1OffsetY= (offset to this particle, default 0) and Spawn1InheritHouse=true (house colors, default false)
;
; While a particle animates (timers are in ticks of 5 ms):
; FrameDelay=time between animation steps (default 10), FrameDelayRandom=n adds a random 0 .. n-1
; FadeDelay=time between steps while fading out (default: the FrameDelay)
; LastAnimFrame=last frame of the animation, after it the particle fades out or dies, HoldFrame=frame shown while fading out
; FrameCount=number of frames of an animation that loops
; FadeStep=alpha subtracted per fade step, DieAlpha=the particle dies when its alpha gets below this
;   (tracks, squish, orni and carryall explosions die when alpha is at or below it)
; FadeInStep=alpha added per step while fading in, FadeInMaxAlpha=alpha at which fading in stops (default 255)
; NextFrameBelowAlpha=alpha below which the second frame is shown
; WearChance=chance in percent per step that the alpha drops by 1, WearMinAlpha=alpha above which that can happen (tracks)
